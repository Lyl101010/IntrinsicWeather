# 真实夜间道路测试建议（尚未执行）

首次真实端到端任务只验证了官方原始RGB示例与 `A rainy day.`。以下是下一次实验的建议，不是已验证的夜间质量结论，也不启动新的GPU任务或服务。

## 输入准备

先选一张有权用于实验的真实夜间道路RGB照片，以PNG或高质量JPEG保留原图。道路边界、车道线和建筑轮廓应能辨认；第一张优先选择曝光较正常、运动模糊较少、灯光没有大面积溢出的画面。极暗、强车灯眩光或已经暴雨模糊的图片可留作后续困难样例，避免第一次同时引入多种不确定性。

建议至少512×512，优先准备约1024×1024的道路主体方形裁剪。当前官方预处理会直接缩放成512×512，宽幅图片会被拉伸；若裁剪，原文件不覆盖，另存输入副本并记录原图SHA256、裁剪坐标和副本SHA256。保留可辨认的道路/天空/照明区域，不用AI增强或先行天气合成。输入上限为2500万像素。原图、裁剪副本、EXIF及其他个人文件均留在Git排除的 `outputs/` 或实验目录中。

第一张结果和保护记录评审后，再决定是否在同一输入上仅替换prompt、仅更换seed或调整一个guidance参数。每次只改一个变量，分别记录任务身份；不自动启动这些后续对照。

## 评价与验收

流程验收检查上传原图与五图/最终图是否同任务同输入，五图是否在最终图前显示，四图条件/None约定是否正确，是否保留raw/PNG/参数/下载，两个worker是否顺序退出、无残留、显存恢复；同时记录加载/生成全程、RSS、available和GPU采样峰值。

本征图评价先做数值检查：五张float数组形状、dtype、有限值、范围、方差和raw/PNG一致性。再看Albedo是否把大面积灯光误当材质、Normal在道路和建筑边缘是否连贯、Roughness/Metallic是否出现大范围异常常量或噪声。Irradiance应展示并保留，但本版本不将它作为Forward条件；不要把它解释为校准的物理照度，也不要把RGB Normal直接当未编码的有符号向量。

最终图与经过同样512预处理的原图并排检查：是否仍为夜间；雨线、路面湿润与反射是否协调；车道线、路缘、建筑轮廓、车辆和行人是否被增加/删除/扭曲；灯光是否产生不合理光晕或过曝；是否有局部涂抹、重复纹理和细节丢失。可把“夜间保留、天气表达、结构保留、伪影”各记0/1/2分并写出具体区域，评分规则在运行前固定。这是人工探索性记录，不是论文基准指标或道路安全能力证明。

没有同视点、同目标天气的真实参考图时，不将输入与生成图之间的PSNR/SSIM当成目标天气正确性的证据：天气和照明变化本就会改变像素。若后续获得配准的目标天气参考，可另行设计定量评估；首轮优先保留全部原始输出和明确的问题截图。

当资源保护触发、输出无效、下载损坏、身份不一致或进程清理失败时，停止并报告，不自动重试。结果明显变白天、结构严重破坏或属性图异常时，先保留证据并定位分解/合成阶段，不能仅凭“有雨线”认定实验质量达标。请提供输入图片并明确批准后再执行下一次真实GPU任务。
